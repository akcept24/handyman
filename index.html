Before you request

Frequently asked questions

Clear expectations make the first conversation more useful.

Does submitting the form confirm an appointment?

No. It starts a project review. Availability, scope, estimate details, and scheduling must be confirmed separately.

Why do you need my ZIP code?

It is used to check whether the project location is within the current service range before discussing an appointment.

Can I request several small jobs at once?

Yes. List each item in the project details so the full scope can be reviewed together.

What if my project requires a permit or licensed contractor?

It will not be accepted as ordinary handyman work. Projects outside the legally permitted scope must be declined or handled by an appropriately licensed contractor. The initial review helps identify that before scheduling.
