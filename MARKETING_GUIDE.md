**Campaign 2: Search - Non-Branded**
- Budget: $50/day
- Keywords: 
  * [emergency handyman]
  * [handyman near me]
  * "home repair services"
  * +licensed +handyman +california

**Campaign 3: Google Local Services Ads**
- Budget: $30/day

- Badge of trust

#### Day 5-7: Facebook Ads Setup
**Campaign 1: Lead Generation**
- Budget: $30/day
- Objective: Leads
- Placement: Facebook + Instagram Feed

**Ad Sets:**
1. Homeowners 30-50 in LA
2. Homeowners 40-60 in Bay Area
3. Lookalike - Website visitors

**Ad Creatives:**
- 3-5 image ads (before/after)
- 2 video ads (service showcase)
- 2 carousel ads (services)

### Week 2: Optimization

#### Daily Tasks:
- Проверка качества лидов
- Ответ на запросы < 1 часа
- Анализ keyword performance
- Тестирование ad copy

#### Metrics to Watch:
- CTR > 2% (Search)
- CTR > 1% (Display/Social)
- CPC < $3
- Form completion rate > 5%
- Phone calls tracking

#### Optimization Actions:
- Pause keywords с CTR < 1%
- Increase bid на top performers
- Add negative keywords
- Test new ad copy variations

### Week 3-4: Scaling

#### If CPL < $50 и quality высокое:
- Увеличить бюджет на 20-30%
- Расширить keyword list
- Добавить новые ad sets
- Запустить remarketing

#### If CPL > $75:
- Пауза слабых keywords
- Улучшить ad copy
- A/B тест landing page
- Проверить mobile experience

```

**Detailed Targeting:**
```

- HGTV

EXCLUDE:

```
✅ Facebook Feed

✅ Instagram Explore
❌ Audience Network (test later)

```

### Ad Creative Guidelines:

**Images:**
- Size: 1200x628px (1.91:1)
- Text overlay: < 20% of image
- Show: Before/After, Team, Quality work
- Avoid: Stock photos, generic images

**Videos:**
- Length: 15-30 seconds
- Square format: 1080x1080px
- Captions: Always ON
- First 3 sec: Hook (problem/pain point)
- Last frame: Clear CTA

**Ad Copy Formula:**
```
HEADLINE (40 chars):
"Fast, Licensed Handyman in [City]"

PRIMARY TEXT (125 chars):
[Pain point] → [Solution] → [Trust element] → [CTA]

Example:
"Broken faucet? Cracked wall? We fix it TODAY. 
Licensed & insured. 500+ 5-star reviews. 
Call now for FREE estimate! ⭐"

CTA BUTTON:
"Get Quote" or "Learn More"
```

## 📞 Lead Response Best Practices

### Speed to Lead:

```
< 5 min: 21x more likely to convert
< 1 hour: 7x more likely
< 24 hours: baseline
> 24 hours: 60% less likely
```

### Response Template:

**SMS (Immediate):**
```
Hi [Name]! This is [Your Name] from California Handyman Pro. 

Thanks for your request for [service]!

I'll call you at [phone] in the next 10 minutes to discuss. 

If that doesn't work, reply with a better time!
```

**Phone Call Script:**
```
"Hi [Name], this is [Your Name] from California Handyman Pro. 

I got your request about [service]. Is now a good time to chat for 2 minutes?

[Listen to their needs]

Great! I can have our expert [technician name] come by [proposed time]. 
Does that work for you?

[Confirm details]

Perfect! You'll receive a confirmation text shortly. 
Looking forward to helping you!"
```
